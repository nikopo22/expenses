## Автор

## Назначение проекта
Кошелёк - консольная программа для учёта личных расходов. 
Возможности:
* Добавлять траты с указанием категории и суммы.
* Просматривать текущий список всех расходов.
* Выводить наглядную статистику по категориям.

## Инструкция для запуска
1. Убедитесь, что у вас установлен **Python 3**.
2. Откройте терминал в папке с проектом.
3. Запустите программу командой:
   ```bash
   python main.py
## Проверка работы проекта

В рамках задания были проверены два сценария: обычный и граничный. 

### Сценарий 1: Обычный
| Действие пользователя | Ожидаемый результат |
| :--- | :--- |
| Выбор пункта `1` ➔ категория `"Транспорт"` ➔ сумма `"150"` | Программа выводит: `Расход добавлен!` |
| Выбор пункта `2` (Показать статистику) | Программа выводит: <br>`Транспорт: 150.00 RUB`<br>`ИТОГО: 150.00 RUB` |

### Сценарий 2: Граничный
| Действие пользователя | Ожидаемый результат |
| :--- | :--- |
| Выбор пункта `1` ➔ категория `"Одежда"` ➔ сумма `"пятьсот"` | Программа не падает, выводит: `Введена некорректная сумма`. Список расходов не меняется. |
| Выбор пункта `1` ➔ категория `"Одежда"` ➔ сумма `"-500"` | Программа выводит: `Введена некорректная сумма`. Расход не добавляется. |
